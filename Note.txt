ตอนพัฒนา จะเปิด 2 Terminal

Terminal 1:

cd backend
python -m venv .venv (รันตอน clone โปรเจคมาครั้งแรก)
.\.venv\Scripts\Activate.ps1(ถ้าจะออกจาก .venv ให้พิมพ์ deactivate)
pip install -r requirements.txt (ติดตั้งไฟล์ที่จำเป็น)
python manage.py runserver (รันbackend ตอนนี้ยังไม่มีข้อมูลจ่ะอิอิ)

________________________________________________________________
Terminal 2: 

cd frontend
npm install(ติดตั้งไฟล์ที่จำเป็น)
npm run dev(รันfrontend)
